# Numera

An exact-arithmetic calculator for Android.

Most calculators answer `1 ÷ 3 × 3` with `0.9999999999999998`. Numera answers `1`, because it
computes with exact rational numbers and constructive reals rather than floating-point
approximations.

- [Privacy policy](privacy-policy.md)

## What it does

Scientific calculation, a 16-category unit converter with exact conversion factors, a
programmer mode with a tappable bit grid, function graphing, date arithmetic and financial
calculators — in twelve languages, with no internet access, no ads and no tracking.
